# PAMS (Process Architecture Management System)

Next.js 16 + TypeScript + Tailwind CSS + Shadcn/ui + next-intl

## Getting Started

```bash
cd pams
npm install
npm run dev
```

- 기본 URL: [http://localhost:3000/ko/dashboard](http://localhost:3000/ko/dashboard)
- 지원 locale: `ko` (기본), `en`, `zh-TW`
