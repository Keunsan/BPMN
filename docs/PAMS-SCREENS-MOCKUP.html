다른 AI에게 문의할 때 — 프롬프트 예시

B2B 엔터프라이즈 PAMS 시스템의 5개 핵심 화면 UI 목업(HTML)을 첨부합니다.

화면 목록:
1. 모델 목록 — BPMN 카드 그리드 + 새 모델 Dialog
2. Task 속성 관리 — 좌측 트리 + 14컬럼 DataGrid + 800px 편집 Sheet
3. 시스템 연계 — L4 태스크 + 연결/가능 시스템·화면 4분할 그리드
4. 태스크-테이블 연계 — L4 태스크 + 연결/가능 외부 테이블 그리드
5. 운영 지식그래프 — 3단 패널(탐색·캔버스·Inspector) + React Flow 그래프

공통 패턴: Shadcn/Tailwind, 좌측 FilterPanel(리사이즈), floating card 그리드, B2B SaaS 톤

문의:
- 5개 화면 간 UX·비주얼 일관성 개선 방향
- Task 매핑 3종(속성/시스템/테이블) 화면의 패턴 통일 vs 차별화
- DataGrid 14컬럼 밀도·가독성 개선
- 운영 지식그래프 캔버스·Inspector 정보 계층
- BPMN 카드 그리드 vs 목록형 대안
