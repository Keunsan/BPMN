등록 패널 — L1 프로세스 신규 등록

Sheet (우측 슬라이드) 헤더 또는 트리 내 「+ 등록」 클릭 시 열림. 실제 구현은 Dialog가 아닌 Sheet side="right" (최대 768px).

상단 「등록」 버튼 → parentId: null → L1 루트 프로세스 등록. 적용 범위(scope) 필드는 L3 등록 시에만 표시됩니다.
